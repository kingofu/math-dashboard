# AI数学教学与学术工具导航 (AI Math Tools Dashboard)

一个支持实时检索、自动归类、智能标签的学术与教学项目导航中心。

## 🌟 特性
- **响应式布局**：完美适配 PC 端与移动设备。
- **动态分类**：左侧高度集成的紧凑型分类标签栏，支持独立滚动与对齐。
- **实时检索**：支持名称、简介、标签多维度实时模糊搜索与 Star 数排序。
- **多主题切换**：内置赛博暗夜、亚光纯白、复古典藏、极简北欧、工业钛灰五款高颜值主题。

## 🛠️ 部署说明
该项目为纯前端静态页面，可直接双击 `index.html` 本地运行，或一键部署至 GitHub Pages。
